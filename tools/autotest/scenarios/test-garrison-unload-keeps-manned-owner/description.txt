Emptying a garrisoned building's SHELTER while its firing ports are still manned must not hand the building to Neutral. Cargo's own revert (CargoInfo.Neutral, in UnloadCargo) fires on PassengerCount == 0, which counts the Cargo hold alone — and a soldier deployed to a firing port has been removed from the hold — so before the fix the house went neutral while its men went on shooting from it. Drives the real player gesture: the class-grouped unload menu (hotkey UnloadMenu), which issues UnloadCargoPassenger and is NOT gated against garrison buildings. Then clears the ports and asserts the building does revert once genuinely empty, so the fix is not just a suppression.
