What we're choosing

Pick a visual direction for the right-side column of the skirmish lobby. Each variant uses the same content in the same order — OPTIONS (Economy → Match → World), ACTIVE CHANGES, PRESET — but rebuilds the spacing, typography, and component vocabulary from scratch.

The left-side mock (gray panel) is a placeholder for the map / players area so you can judge the column in proportion. Once we pick one, we'll port it to the in-game chrome — some details (gradients, rounded corners) won't fully translate, but the layout, hierarchy, and visual language will.

ACrisp · Linear / Vercel

Clean cards with thin dividers. Two-column dropdown grid, modern toggle switches. Each value that's been changed from default gets a small green dot next to it; active changes summarize the same info as pill chips at the bottom. Preset bar reads as a footer toolbar.

Translates well to in-game: cards = ColorBlock panels, accent dots = small ColorBlocks. Toggle switches need a custom widget but can be faked with two ColorBlocks + IsChecked logic.

BSpacious · Notion / Tailwind UI

Label-value rows with breathing room. Each row gets one option, with the value right-aligned and changed values highlighted in accent. No card boundaries inside the section — relies on horizontal dividers and big section headers. Sub-text under settings adds context without clutter.

Lighter on chrome — easiest to translate to OpenRA, since most of it is just label + dropdown + thin divider line. The right-aligned value style works because OpenRA dropdowns can have a configured text alignment.

CCockpit · dense pro-tools

Maximum information density. Jump-link nav at top, full-bleed section headers, tight rows with a 2px accent rail on any changed value. The active changes chip lives inline at the bottom; preset bar runs along the very edge. Best for power users who want to see everything at a glance.

Easiest to translate to in-game — already close to what we have, just tightened up. Accent rails are 2px ColorBlocks; jump nav can be plain buttons.

DHero metrics · game launcher

Top-level economy values shown as big metric cards — the kind of "at-a-glance" display you'd see in a game launcher or fitness dashboard. Match settings collapse into compact rows; world toggles render as pill buttons. Changed values glow. Active changes get a prominent badge.

Most ambitious — large numeric values, pill buttons with glow effects. The big-number metric cards are achievable as plain ColorBlock + Label combinations; the glow effect can be faked with two stacked ColorBlocks.

EGrouped cards · clean form

Each section lives in its own rounded card with a header strip. Inside, options run as two-column key-value pairs. Active changes get a distinct "diff" treatment — original value struck through, new value in accent. Section header shows a small "1 modified" pill when anything inside is changed.

A middle ground between A and D. The "modified" pill on the section header is information-dense; the strikethrough diff in Active Changes shows what changed and from what value. Both work in OpenRA chrome but the strikethrough needs custom text rendering or two stacked labels.
