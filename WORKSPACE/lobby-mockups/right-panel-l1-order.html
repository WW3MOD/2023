O2Gameplay pillars — Money / Pace / Visibility / Rules

Re-groups by what the setting actually does to the match, not where it lives in the codebase. Money = economy. Pace = how fast the game runs (speed, tech, time limit, veterancy). Visibility = fog of war, map reveal, separate spawns. Rules = victory mode, friendly fire, powers, debug. Mirrors how a host thinks: "what kind of match am I setting up?"

O3Flat — no categories at all

Drops the section headers entirely. ~16 cards in one continuous 4-wide flow, ordered by how often a host changes them (top row = most-likely-to-touch, bottom row = "you almost never touch this"). The visual rhythm of the grid is the only structure. Best embraces "less is more" — the player just scans.

O4Changed first — pin modified, defaults follow

Anything modified bubbles to the top in a small pinned strip ("MODIFIED · 1"). Everything else lives below as a flat grid with no section labels, defaults-quiet. Reading order matches what matters: "what's different from the standard match?" comes first; the rest is reference. Drops categorisation, keeps a single semantic distinction (changed vs default).

O5Minimal — cards and that's it

"Less is more" pushed all the way. No section headers, no preset chips, no search bar. Just the cards in a single column-flow, grouped by visual rhythm — values in the first half, toggles in the second. Section identity is implicit (you can see "this row is about money", "this row is about visibility") without anyone having to label it. The bottom strip is the only chrome.
