All-hero, expanded — layouts × independent features

Every option is a hero card (the "all hero" treatment from the previous round). What changes between variants is how those cards are laid out and which feature decorations are applied. Each variant renders all six features in context so you can compare — then you can call out exact combinations like "Layout 2, features 1 + 3 + 6".

Layouts

  • L1 Uniform 4-wide grid — every card same size, sections separated by header rows
  • L2 Masonry — feature cards span 2 or 3 cols, "headline" metrics get more visual weight
  • L3 Section bands — each section runs edge-to-edge with a subtle bg tint
  • L4 Compact 6-wide — denser grid, smaller cards, fits more on one screen
  • L5 Two-column — Economy takes the wider left half; Match + World stack on the right

Features (additive)

  • F1 Default badge — "DEFAULT" or "+$200" pill on each card
  • F2 Inline expand — clicking a card reveals options inline instead of opening a dropdown overlay
  • F3 Preset chips — quick presets (Standard, Long Game, Cash Rush) at the top
  • F4 Search bar — type to filter visible cards by name
  • F5 Section reset — small "reset section" link in each section header (highlighted if any change in that section)
  • F6 Live impact — small derived-info line under the value ("≈ 5 light tanks")
e.g.  Layout 2, features 1 + 3 + 6  — masonry layout, default badges, preset chips, live impact line
