Q4 locked — tabs moved into the panels, no more global Map/Music toggle

Layout is now fixed: map TL, settings BL, players TR, chat BR. Players list auto-sizes to the slot count + spectator, chat fills the remainder.

What's locked: the quadrant arrangement and the Q4-style "chat eats the slack" sizing.  What's moved: the Map / Music switch is gone from the global top bar — Music is now a tab inside the Settings quadrant, and the map area gets its own Map / Change Map tabs that swap the preview for an inline map picker (no modal).  What's varying below: just the tab style and the inline map-list density.

M1 / M2 / M3 each show the lobby in the normal "Map preview" state with one tab style. M4 takes M1's tab style and shows what happens when you click Change Map — the inline map list opens in place.
