2×2 quadrant layout — same structure, different proportions

Every variant uses the same arrangement: map top-left, settings bottom-left, players top-right, chat bottom-right. What changes is the height each row gets — pulling rows up or down to emphasise different parts of the lobby.

┌─────────────────┬─────────────────┐ │ │ │ │ MAP │ PLAYERS │ │ │ │ ├─────────────────┼─────────────────┤ │ │ │ │ SETTINGS │ CHAT │ │ │ │ └─────────────────┴─────────────────┘

The chat is now a dedicated quadrant, not a strip at the bottom — proper compose row, big history area, optional commands ("mode" pill on the left of the compose). Settings keep the locked-in O3 flat layout, just resized to its new home; Q2 widens it to 6 columns since the area is wider in that variant.
