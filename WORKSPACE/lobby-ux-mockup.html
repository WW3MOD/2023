The only cue is the word "Spectator", which the redesign deliberately toned down to regular weight. Three alternatives follow. All three are chrome only.

2Getting back from spectating — and the dead end

Going to spectator is one click. Coming back has no button at all: the whole strip is hidden while Slot == null (LobbyLogic.cs:321), so a spectating host also loses the "Allow Spectators?" checkbox.

in a slot ☐ Allow Spectators?Spectate

The dead end (two clicks, both prominent). Click Add Bots → every empty slot is now a bot. Click Spectate → you are out. There is now no empty slot to return to, slot_open is admin-gated (LobbyCommands.cs:463), and the host has no "move to player" action to rescue you. A non-host must leave and rejoin the server.
ProposedThe button swaps
in a slot ☐ Allow Spectators?Spectate
spectating ☐ Allow Spectators?Join as player
no slot free Join as player disabled — "All slots are full"
Same strip, same place, label follows your state. Issues slot <key> — the same order the "Play in this slot" button already sends.
Pair it with: a "Move to player" entry in the host's dropdown, mirroring the "Move to Spectator" that already exists (LobbyUtils.cs:134-140). Together they close the dead end from both ends.
Cost S. Existing order. No new synchronised state.

4The thing nobody asked about — Advanced may open onto nothing

Traced statically, and the most likely thing to embarrass the project in front of a stranger.

Today (inferred)An empty top-level tab
Match Advanced Music
(no options)
The chain. 34 lobby options exist — "Weapon Range", "Snipers", "MANPADS" — and every one is stamped a placeholder (LobbyDummyOptions.cs:36-38). The renderer correctly hides any section that is entirely placeholders (LobbyOptionsLogic.cs:379-380). All three Advanced sections are exactly that. The only real fallback, the Scenario dropdown, yields nothing on a map without scenarios (ScenarioLobbyDropdown.cs:27-29) — the normal case.
Verify before acting. This is a source read, not a screenshot. It is false if any non-placeholder option exists outside the 12-item Common allow-list and the 6-item hidden list. I checked and believe it holds — but one screenshot settles it and should be taken first.

Unreachable today; live the instant one real option joins those sections. One line to pre-empt.

Preset bar — PRESET [Default ▾] [Save As] [Reset] holds permanent space on the main panel for a feature a first-time player cannot use, and "Replay last" in the setup row is the same thing in one click.
