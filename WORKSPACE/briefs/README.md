# Briefs

Dispatch-ready briefs from the docs lane. The code lane picks top-down; a brief is meant to be handed
to an implementer verbatim.

Each brief carries the SHA it was read at. Line numbers rot — if the tree has moved, re-grep the cited
symbol before acting rather than trusting the number. A brief marked *hypothetical* names a premise the
groomer could not settle from source; settle it first.
