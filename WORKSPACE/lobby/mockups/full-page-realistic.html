Implementation spec — what gets ported to OpenRA chrome:

  • Layout. 2×2 quadrants. TL Map (720×480), TR Players (rest×380, auto-sized to slot count), BL Settings (720×rest), BR Chat (rest×rest). 10px gutters. 16px outer pad.
  • Palette C — cool slate · steel. Panels #161a1f, banners #1e242c, accent #a8b5c4, ink #d8dde4. Green #6ec890 only for ready ticks and Start Game.
  • Bevels. Every panel and button: 1px #3e4754 top+left, 1px #050709 bottom+right. Composable from 4 ColorBlockWidgets each.
  • Fonts. Sized to WW3MOD's actual stack: Bold 14 (default), MediumBold 18 (player name, spawn, ready, settings value), Tiny/TinyBold 10 (labels, system tags), Small 12 (sub-text).
  • V5 player rows. 28px color tile · 40×26 flag · 28px spawn · name (with HOST badge / AI tag) · 18px ready tick. HOST badge is a 1px-bordered 11px label in steel on the host's row.
  • O3 flat options. 12 hero tiles in a 4-wide grid, ordered by frequency-of-change. Each tile: 60px tall, label (Tiny) over value (MediumBold). Toggle = chunky 26×14 rect, dropdown = ▼ chevron bottom-right.
  • Tabs. Underlined uppercase text (TinyBold). Active = steel color + 2px steel under-rail. Map / Change Map in TL, Settings / Music in BL, Players (4/6) in TR, Chat in BR.
  • Map browse. Clicking Change Map swaps the map panel body in-place — search bar + filter chips + 3-column card grid. No modal.
  • CTA bar. Left: stat strip (Slots / Players / Bots / Spectators). Right: chunky ✓ Ready toggle + 11×44 green ▶ Start Game.
  • Corner brackets on map only. 12×12 steel L-marks in each map preview corner. Westwood signature touch; not used elsewhere to keep them rare.
  • Hover = darker bg, no transition. OpenRA repaints, nothing animates.

Engine touchpoints (from WORKSPACE/lobby/next-steps.md): engine/mods/common/chrome/lobby.yaml, lobby-mappreview.yaml, lobby-players.yaml, lobby-music.yaml; LobbyLogic.cs, LobbyOptionsLogic.cs, MapPreviewLogic.cs, LobbyUtils.cs. Recommended port order: Settings (easiest, mostly there) → Map (needs inline browse) → Players (V5 row template) → Chat (cosmetic).

Implementation target. Every primitive used here maps to a single ColorBlockWidget, LabelWidget, or ButtonWidget in OpenRA chrome.
