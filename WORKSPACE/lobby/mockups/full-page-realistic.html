What changed vs full-page-final.html (the modern-web mockup):

  • No rounded corners. Every panel, button, swatch is square. OpenRA can't render border-radius.
  • Bevels replace shadows. Each panel/button gets a 1px lighter top+left and 1px darker bottom+right line — the only "depth" trick available with ColorBlockWidget.
  • Type sized down. Player name dropped 26→18 (BigBold isn't a thing the lobby usually uses for rows; MediumBold 18 is the realistic ceiling without a custom font). Spawn letter dropped to match.
  • Amber tactical accents instead of green section headers. Green is reserved for "go" states only — ready tick, Start Game button. Cleaner read.
  • Corner brackets on the map — the Westwood touch. Four 14×14 amber L-marks, just sprite overlays in OpenRA.
  • Hover = darker fill, no transition. OpenRA toggles the bg color on hover; nothing animates.
  • Toggle switch is a chunky 2-state rectangle, not a soft pill. Amber/dark for off, dark-green/green for on.
  • Subtle background grid in the stage picks up the blueprint reticles in uibits/dialog.png. In-game it'd be the actual sprite tiled.

What's still here from the locked design: 2×2 quadrant layout, Map+Change-Map / Settings+Music tab pairs, O3 flat option grid (4-wide, no category headers), V5 player rows (color · flag · spawn · name · ready), single green Start Game CTA, dynamic player-block sizing.

Open calls if you like this direction: (1) corner brackets on every panel or just the map? (2) keep the amber section accent or stay green? (3) toggle switch — chunky rectangle or just two text labels with one underlined?

Realistic mockup grounded in OpenRA's ColorBlockWidget + bitmap fonts. No CSS feature used here is impossible in-game.
