Player list — drop the avatar, scale up the type

Each variant renders the players quadrant at its actual 1248 × 524 size for a 1440p lobby. Avatar gone, name dominates, everything else right-sized to support it. Four directions:

  • V5 Color-led ★ (new) — fixed left-to-right sequence: large color tile, big faction flag (no caption), mono spawn letter, bold name, ready tick on the right. No sub-meta.
  • V1 Bold name — single line per slot, 26px name, faction text + small flag, color dot, spawn letter, ready tick. Lots of horizontal breathing room.
  • V2 Color edge — 4px color stripe on the row's left edge as identity. Two-line: 22px name on top, faction · spawn · status as a quiet sub-line.
  • V3 Faction-led — subtle faction-tinted background per row + 3px team accent stripe. Big flag plate on the left, name beside, color bar replacing the swatch.
  • V4 Justified columns — table feel with explicit column headers ("NAME · FACTION · COLOR · SPAWN · READY"). Big name with the AI tag as a quieter sub-line. Spawn rendered in a mono-tile.

Responsiveness note: at 1440p these all breathe. At 1080p the same rows would compress horizontally — V2 (color edge) and V4 (justified columns) hold up best because the column count is smaller. V1 and V3 lose less if the right-side columns shrink first.

V1Bold name · single big line

Player name is the hero, everything else lives in service to it. 26px bold for the name, AI variant tag at 13px inline. Faction text + small flag, color as a 18px round dot, spawn letter at 22px mono, ready tick at 26px. The avatar's column-worth of width has all been redistributed into name.
