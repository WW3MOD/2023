Full lobby with O3 Flat locked in

The right-side column is now identical across all four: the flat 16-card hero grid you chose, with the bottom-strip Active Changes + Preset bar. What varies between propositions is the entire left side (map + players + chat) and the page chrome (top header, bottom Start Game CTA).

Frames are 2560 × 1440 at native pixel size, so each one represents what you'd see fullscreen on a 1440p monitor. If your browser viewport is narrower, the frames will scroll horizontally — that's expected.

P1Classic refined

Players in a tighter table with a colored avatar circle, faction flag pill, and a small ready tick. Chat as a 140px panel at the bottom. Start Game gets a big highlighted hero button in the centre of the CTA bar — flanked by ready status and map context.
