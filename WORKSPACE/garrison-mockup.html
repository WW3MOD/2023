What is not being proposed

No new simulation state, no new order, and no change to how suppression accumulates or decays. Everything above is read at render time from GetConditionCount("suppressed") — the same synced actor state the simulation already reads. There is no desync surface because nothing is written.

Separately: PortState.IsDucking is written every tick and read by nothing. It is a vestigial duplicate of ^SuppressionBurstMultiplier, not a missing feature — wiring it to rate of fire would double-apply a penalty that already ships. The proposal is to delete it.
