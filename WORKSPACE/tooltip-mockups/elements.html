Element vocabulary

Eight typed elements. Each has one style, defined once, so an author never chooses formatting — they choose a kind. All eight compose from two widgets OpenRA already has: LabelWidget and ColorBlockWidget. No new widget class is required, only a layout container and a per-kind style table. Sizes are the mod's real registered fonts (mod.yaml:290-316); colours are the canonical grayscale from chrome/_lobby-palette.yaml.

Deliberately not included

Table / grid No tooltip datum needs more than two columns. StatRow already aligns values; a grid would be a new widget with no caller.
Icon + text row Would need a sprite per stat and a sheet to hold them. The right rail already carries the only two icons that exist (production-tooltip-cost, -time).
Progress / pip bar The depot meter is a CostRow sub-part, not its own element — it never appears without a cost above it, so it has no independent vocabulary.
Rich inline markup Bold/colour spans inside a string would re-open exactly the ad-hoc formatting this design removes. Styling is a property of the row's kind, never of characters an author typed.
