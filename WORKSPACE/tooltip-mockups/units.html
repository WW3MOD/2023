One template, four unit classes

The same element order renders all four. Nothing is special-cased — rows that have no data simply do not emit. Every number is computed from shipped YAML at main @ b3a7564d; refill figures and Logistics Centre fractions are from the priced table in wt/supply-economics @ 1b1e1d9d:WORKSPACE/supply-cost-audit.md. Depot reference throughout: 1 Logistics Centre = 2250 supply (structures.yaml:466); a supply truck holds 750 (vehicles.yaml:569).

No armament rows, no refill row — they have no data, so they do not emit. The StatRow/CostRow/Note vocabulary is unchanged.

Caveat, and it is a real one. No structure is buildable in WW3MOD — all 16 Buildable: blocks in structures-defenses.yaml are ~disabled, and the LC is fielded by deploying an LCCV. So a structure never appears in the production tooltip at all. Its live surface is the world tooltip (WORLD_TOOLTIP, tooltips.yaml:61-89), which today shows name, owner flag, and nothing else — the 2250 it holds is not surfaced anywhere. Reaching this panel means extending that second widget too, which is not included in the "smallest viable first step" costed in the audit.
