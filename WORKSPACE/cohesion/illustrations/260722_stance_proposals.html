Cohesion stances — what each should mean

Grounded in the code as of main 6b720067. Legend for all diagrams:

1 · Today: one behavior, three spacing numbers

All three stances run the same four intent bidders (Open box / SpreadInside / EdgeLine / Approach). The stance only swaps the grid spacing constants. So "Spread" = the same box or cover-bid, stretched. Nothing else changes: same leash, same assignment, same travel behavior.

Tight: small box on the click.
Loose (default): same box, more air.
Spread: same box, stretched. No new intelligence, just distance.

2 · Why Spread feels strange — three compounding causes

Slot i goes to the unit with the i-th lowest ActorID, not the nearest unit. Paths cross; wider spacing = longer crossings = more visible chaos. (as-built §10.C)
In cover, Spread's large min-spacing disqualifies the good cells near trunks — one unit gets the trunk, the rest get whatever open cell satisfies the spacing. The formation looks random.
No ghost markers or cue: the player can't tell a deliberate dispersed formation from units wandering. Even correct output reads as broken. (problem §3.6 — called the single biggest item)

3 · Proposal: give each stance an identity, not a number

Keep the intent classifier (it works — verified by the river-zeta probes). Change what a stance means: each stance gets its own formation template, its own cover policy, and its own leash strength. One sentence each:

StanceIdentityFormationCover policyLeashYou accept
TIGHT"Column — move fast, stay together"Column of 2 along approach axisIgnores cover, prioritizes speed + roadStrong snap-backAoE vulnerability
LOOSE"Combat interval — fight from cover" (default)Current box/wedge, current spacingCover-bid wins vs geometry (bend the line)MediumSlightly untidy lines
SPREAD"Dispersed — survive artillery"Staggered irregular line, min interval ≥ AoE radiusEvery unit seeks its own cover micro-posWeak (units keep local freedom)Slow, loose arrival

3.1 TIGHT = column. The travel/convoy stance.

Not OpenRA's converge-to-one-point: arrival is a short column (bounded footprint), not a blob. Reads as a convoy. Natural for roads, rear-area moves, mounting up.

3.2 LOOSE = combat interval. What we have, made trustworthy.

Today a unit stands in the gap if its trunk is >2 cells off the geometric line (LineSlotSearchRadius=2). Fix: widen the search and let cover win over line shape — problem doc behavior F.

3.3 SPREAD = dispersed. The anti-artillery stance.

Spacing is derived from the artillery AoE radius (a game fact, not an arbitrary number), stagger breaks the straight line, and each unit does its own local cover-seek. Irregular on purpose — the preview makes that legible.

5 · Decision points

DP-1 · Tight = column? Column-of-2 travel identity vs today's small box. The column is the biggest visible change of the proposal.
DP-2 · Spread spacing from AoE radius? Derive the interval from a real weapon's blast radius (self-explaining) vs keep a hand-tuned constant.
DP-3 · Cover beats line-shape in Loose? Bend the EdgeLine freely to get every unit a trunk (messier line, better cover) vs keep lines mostly straight (readable, some units exposed).
DP-4 · Preview ghosts in scope? Include fix #2 in this work (bigger scope, biggest payoff) or defer to its own item.
DP-5 · Ordering. Suggested build order: fix #1 (assignment) → stance identities → leash #4 → travel #3 → preview #2. Reorder freely.
