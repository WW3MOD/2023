The Options tab

Answering the user’s question directly: why is it empty, and what belongs in it.

It is not a spectator problem. The tab is empty for everyone — player and spectator alike. Chain: the in-game options panel (engine/mods/common/chrome/ingame-info-lobby-options.yaml) has no Label@CATEGORY_FILTER, so LobbyOptionsLogic falls back to CategoryAdvanced (LobbyOptionsLogic.cs:229-230). Every working option — fog, starting cash, game speed, time limit — is classified Common (:71-86) and is therefore filtered out. What remains is LobbyDummyOptions, and every option that trait produces is stamped Placeholder = true (LobbyDummyOptions.cs:37). A section made entirely of placeholders is skipped outright (LobbyOptionsLogic.cs:379-380). All three Advanced sections are all-placeholder, so all three vanish. PowersLobbyOptions, the only other source that could have landed in “Other”, is commented out at mods/ww3mod/rules/world.yaml:555. Nothing is left to draw.
The fix is one label. Adding Label@CATEGORY_FILTER with Text: Common to the in-game panel populates it immediately, read-only — GameInfoLogic already passes configurationDisabled: () => true (GameInfoLogic.cs:172), so the controls render disabled with no further work. Everything in Frame 2 below except the SPECTATOR section is reachable that way.

What is reusable versus what is new work

FREE Match / Economy / World sections. One Label@CATEGORY_FILTER: Common. The rows, the disabled styling and the tooltips are all existing LobbyOptionsLogic behaviour.
FREE-ish Section headers. Need a SECTION_HEADER_TEMPLATE in the in-game panel; AddSectionHeader silently no-ops without one (LobbyOptionsLogic.cs:261-262). Copy the lobby's template.
REUSE Fog view. ObserverShroudSelectorLogic already implements All Players / Disable Shroud / per-player and is mounted as SHROUD_SELECTOR in mods/ww3mod/chrome/ingame-observer.yaml. Mounting a second instance here is wiring, not invention.
REUSE Stats overlay. Same story — the observer's STATS_DROPDOWN with its eight modes.
NEW Follow selected player. Genuinely does not exist. The observer stats panel only does a one-shot jump to a player's base on row click; there is no continuous camera lock. This is the one item on the wishlist that is real new engine work.
NEW Show all player chat. The Chat tab is hidden entirely when there is only one non-bot client (GameInfoLogic.cs:97-98), which is exactly the 6-AI spectate case. Worth revisiting separately; not part of this design.
