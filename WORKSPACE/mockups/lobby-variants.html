What changes

  • cut Tactical / Strategic / Nuclear Arsenal checkboxes — the ceiling does their job, and with them a host could switch nukes off and leave escalation pointless.
  • cut Doomsday checkbox. Its clock becomes Ending, so the combination that can never fire stops existing.
  • cut Friendly Fire and Powers Enabled — zero consumers, pure decoration.
  • cut Game Mode "Sandbox" — does nothing, and at Start At 2 silently freezes autonomous fire for the whole match.
  • keep Everything else, regrouped under headings that name the question being answered.

Why you might want it

  • Lowest risk. Nothing to relearn, and each cut is defensible on its own.
  • Still a long panel — this fixes honesty, not length.

Pick a game, not a configuration.

Four named game types as cards. Each is a stance the whole match takes. Custom is still there for the people who want the dials.

Game type
Conventional
No nuclear weapons at all. Tanks, aircraft, the Supply Route. Ends when one side can no longer be relieved.
Cold War default
The DEFCON ladder. Closed border, then fire only on your order, then open war — and nuclear release climbs with each detonation.
Dead Hand
Cold War on a deadline. When the clock runs out the map is levelled whatever state the war is in, and the score standing at that instant wins.
Sandbox
Everything unlocked from the first tick, nothing gated, no escalation. For trying things out.
Tune it ▸
Ceiling · pace · starting units · economy · battlefield. Collapsed, and every value shown as the game type set it.

The idea

  • A host picks the experience. The dials still exist underneath and are pre-set by the card — opening Tune it shows what the card chose, so nothing is hidden, only decided.
  • new "Conventional" becomes a real named game rather than the absence of a mode — and it is where a no-nukes match belongs, instead of a ceiling set to HOLD.
  • new "Sandbox" is a game type, so it stops being a mode value that does nothing and a checkbox with the same name.

Why you might want it

  • The lobby stops looking like a settings screen. Four cards read in five seconds.
  • Cards must be honest — if picking one and then tuning it produces something the card no longer describes, that is worse than dials.

There is no "off". Every match is on the ladder — you choose where it starts.

The most drastic: escalation stops being a mode and becomes the spine of the game. A conventional match is simply one that starts at the bottom with the ceiling shut.

The idea

  • Four dropdowns describe every game this mod can play. Opens at DEFCON 1 + Escalates Never + Nuclear release Never is exactly today's conventional skirmish — no separate mode needed.
  • cut The Game Mode dropdown itself. There is nothing left for it to select.
  • new "Escalates: Never" replaces the Sandbox mode value honestly — it pins the level, which is all that value ever did.
  • Each dropdown's values are written as what the player experiences, not as jargon: "closed border", "fire only on order", "open war".

Why you might want it

  • One mental model for the whole game. Nothing overlaps because there is only one axis and two modifiers.
  • Biggest change, and it makes the ladder mandatory — if a player dislikes DEFCON they can only turn it down, never off.
